Jack's PDF — App text review
Version: 1.9 · Prepared: November 5, 2026
185 numbered entries · 20 groups

Complete review of app-defined wording and dynamic text templates, with tooltips, accessibility text and macOS-owned messages separated. Braces identify values supplied by a file, the reader state or macOS.

Typography: Avenir 13 pt for all app-controlled text, including the filename. Native macOS panels retain system-controlled typography.
Header: fixed slots show file size, PDF counter and page counter in that order. The borderless PDF counter includes a small permanent chevron and opens the PDF order menu when folder navigation is available. Filename and containing folder path use the left column, moving above the fixed group only for narrow windows. Selected menu and reader shortcuts are enabled; Hide remains removed; reading arrows and standard dialog Return/Escape remain.

How to review: refer to an entry ID such as T042 when requesting a wording change. Text is exact unless its ownership label says example or generated. Where, Trigger and Note are review explanations, not app copy.

Coverage boundary: all app-owned strings in the current reader are represented. macOS and file-provider wording varies by version, locale and circumstance; its families and representative replacement wording are included, not claimed exhaustive.

SCENARIO BEHAVIOUR AND MESSAGES

Menu commands and reading keys: The selected Open, Save As, Close Window, Quit, Full Screen, zoom and rotation shortcuts are enabled; Find and Save are not. The app menu has no Hide command. Up/down reading and left/right PDF navigation remain, as do standard dialog Return/Escape actions.

Window sizing: The green window zoom button is hidden. View contains only Full Screen (or Exit Full Screen), using Control-Command-F. There is no Window menu.

Switching or closing a PDF: Left/right navigation, Open, Open Recent and Close PDF discard unsaved rotations without a rotation warning. A failed or canceled new-file load preserves the current document and its rotations. The warning appears only when closing the app window or quitting.

Successful save: No success alert or confirmation sentence is displayed. The unsaved-rotation bullet clears.

Loading or saving: A spinner appears and controls disable. There is no app-owned “Loading…” or “Saving…” caption.

Clearing history: A confirmation explains that recent history and saved folder access will be removed. Cancel is the default; clearing occurs only after explicit confirmation. The menu then shows “No Recent PDFs”.

Declining folder access or choosing a different folder: No warning is shown. “Browse folder…” remains available with the accessibility label “Enable folder navigation”.

Folder scan failure: The counter shows “Folder unavailable”, with explanation in its tooltip and “Allow Folder Access…” in its dropdown. Pressing an arrow retries the scan and presents the macOS error if the folder is still unavailable. A failed saved-bookmark lookup follows the existing optional folder-picker flow.

Changing PDF order: No confirmation or success message appears. The current PDF, zoom, scroll position and rotations remain unchanged. Its counter index is recalculated in the selected order; Recent history keeps its last-opened order.

First or last PDF in a folder: An arrow beyond the end does nothing; there is no wraparound or boundary message.

Canceling Open, Save As or a password prompt: No additional cancellation message is displayed.

Starting another app instance: The app keeps a single instance; there is no app-owned second-instance warning.

Blocked editing, PDF actions or printing: No app-owned warning text is displayed. There are no Print, Share, document-properties or editing menu items.

PDF content itself: Page text, existing annotation appearances, form values and image text come from the selected document and are outside this fixed-copy inventory.
